# data/

Generated by `tools/fetch_and_build.sh`; see each script's header for the file format.

| Path | Content | Source |
|---|---|---|
| `neutron/*.nbin` | 66 isotopes (H to Pb): pointwise elastic, capture, other absorption, (n,2n), continuum inelastic and every discrete inelastic level (tagged with the matching RIPL level), 294 K, linearly interpolable, thinned to 0.2 % | ENDF/B-VIII.0 (D.A. Brown et al., Nucl. Data Sheets 148, 2018), via the `openmc-data-storage/ENDF-B-VIII.0-NNDC-json` GitHub conversion |
| `gamma/capture/*.csv` | thermal-capture level schemes with absolute gamma intensities, 51 isotopes | EGAF, IAEA Evaluated Gamma-ray Activation File (R.B. Firestone, Zs. Revay et al.), JSON copy from `AaronMHurst/python_egaf`, **confirm redistribution terms** |
| `gamma/levels/*.csv` | RIPL-3 discrete levels with gamma branching ratios and conversion coefficients, 66 isotopes (levels up to 8 MeV with branches) | RIPL-3 (IAEA) as distributed in the TALYS structure database, `arjankoning1/talys` (MIT) |

| `thermal/hh2o.tsl` | H in liquid water, 293.6 K | ENDF/B-VIII.0 CAB-model S(alpha,beta) (J.I. Marquez Damian et al.) processed with NJOY2016 to ACE; from `marquezj/tsl-HinH2O` (`ace/lib_294.ace`) |
| `thermal/hpoly.tsl` | H in polyethylene, 293.6 K | sampled from NCrystal's `Polyethylene_CH2.ncmat`; free-atom C scattering (4.75 b) subtracted. Not an ENDF evaluation |
| `photon/*.csv` | photoelectric, incoherent, coherent, pair cross sections per atom, 600 bins 10 keV to 20 MeV, 21 elements | Elam tables (`xraydb`) to 0.5 MeV; Klein-Nishina + Bethe-Heitler fit + fitted photoelectric extrapolation above (checked against NIST XCOM, `tests/validate_photon.py`) |
| `dose/*.csv` | ICRP-116 effective dose per fluence (AP, PA, LLAT, RLAT, ROT, ISO) | tables bundled with OpenMC (MIT) |
| `elements.csv`, `isotopes.csv` | atomic weights, abundances, masses, neutron separation energies | `periodictable` |
